# LICENSES

Инвентарь лицензий платформы и её зависимостей (решение **D10**).

**Правило платформы:** код платформы — MIT; в прошивку линкуются **только
пермиссивные** компоненты (MIT / BSD / Apache-2.0). Copyleft (GPL/LGPL) в ядре
платформы запрещён; GPL-инструменты допускаются только на хосте.

## Код платформы

| Компонент | Лицензия | Где |
|---|---|---|
| `abl-mcu-platform` (HAL, soc, boards, runtime, scripts, templates) | MIT | этот репозиторий |
| Проекты-приложения (`abl-mcu-project-*`) | MIT (по умолчанию) | репозитории проектов |

## Vendor-компоненты, попадающие в прошивку

| Компонент | Лицензия | Влияние на закрытый продукт | Где используется |
|---|---|---|---|
| STM32 HAL driver (`stm32f1xx-hal-driver`, `stm32h7xx-hal-driver`) | BSD-3-Clause (ST) | можно | `hal/src/stm32`, `soc/stm32/*` |
| CMSIS Core / CMSIS Device | Apache-2.0 | можно | SDK STM32 |
| ESP-IDF | Apache-2.0 | можно | `soc/esp32`, `target/esp32` |
| FreeRTOS (в составе ESP-IDF) | MIT | можно | `runtime/src/freertos` |
| avr-libc | BSD-стиль | можно | AVR-порт |
| Бинарные блобы wifi/BT Espressif | условия Espressif (свободно распространяемые) | можно (стандарт отрасли) | ESP32-прошивки |

Нотисы vendor-файлов сохраняются как есть: файлы STM32Cube/CMSIS в
`soc/stm32/<family>/<variant>/` и `target/*/extra` **не перелицензируются**.

## Инструменты хоста (в прошивку не попадают)

| Инструмент | Лицензия | Замечание |
|---|---|---|
| `arm-none-eabi-gcc`, `avr-gcc`, `xtensa-esp-elf-gcc` | GPL (компилятор), GCC Runtime Library Exception (libgcc), newlib/avr-libc | сборка закрытой прошивки допустима; GPL относится к самому инструменту |
| OpenOCD, GDB | GPL | запускаются на хосте, в образ не линкуются |
| CMake, Ninja, Python (PyYAML, Jinja2) | BSD/Apache/MIT/PSF | build-time |

## Чек-лист при добавлении зависимости

1. Лицензия пермиссивная (MIT/BSD/Apache-2.0)? Если нет — **в ядро нельзя**
   (максимум изолированный компонент с явной маркировкой и предупреждением).
2. Обновить таблицу выше.
3. Vendor-файлы кладутся вместе с их LICENSE/нотисами.
4. Для CI (план) — автоматическая проверка лицензий на регрессии.
